# Supplementary information (fully editable LaTeX)

- `ESM_1/ESM_1.tex` (+ `ESM_1/figures/`) -- Online Resource 1: the
  finite-population ABM benchmark and direct event-level verification
  (Sections OR1-S1 through OR1-S7, Tables OR1.1-OR1.8, Figs. OR1.1-OR1.4).
  Compile with `latexmk -pdf ESM_1.tex` from inside `ESM_1/`. Every numeric
  table and every figure in this document is generated by
  `../../supplementary_figures/` (S1-S4) -- see that folder's README for how
  to regenerate the underlying data before recompiling. Sect. OR1-S6 reports
  event-level verification statistics from `supplementary_figures/S5/`, whose
  corresponding four-panel scatter plot is now Figure 2 of the main text
  rather than a figure within this document.
- `ESM_4/ESM_4.tex` -- Online Resource 4: analytical and numerical
  supplements for the implicit QSS solution (S4, supporting main-text
  Sect. 4), the perturbative QSS construction (S7, supporting main-text
  Sect. 5), and the Section 6 technical results and large-population
  ABM ensemble protocol (S8). The ESM_4-internal S4/S7/S8 numbering does
  not track main-text section numbers (S7 supports Sect. 5, not Sect. 7).
  Pure analytical/derivational content with no figures or generated numeric
  tables; compile with `latexmk -pdf ESM_4.tex` from inside `ESM_4/`.
- `SUPPLEMENTARY_CAPTIONS.txt` -- the one-paragraph caption for each of the
  four Online Resources, as it appears in the main manuscript's
  Supplementary Information section.

- `ESM_2.xlsx` -- Online Resource 2: the 780-row parameterization table,
  published trajectory-error and convergence summaries, and
  deterministic-reference and event-term checks, as an editable workbook.
  Recovered from an earlier packaging pass and brought current: the
  S->U symbol was renamed back to S throughout (column headers and all
  780 `protocol_id` values), the second author affiliation was restored,
  and the stale `OR1.1-OR1.5` figure range was corrected to
  `OR1.1-OR1.4`. The underlying numeric values (verified against
  `ESM_1.tex` and `figure_generators/GENERATION_REPORT.md`) were already
  current and unchanged by this fix.
- `ESM_3.zip` -- Online Resource 3: a fresh reproducibility-archive
  snapshot of `../figure_generators/` and `../supplementary_figures/`
  (all nine main-text figures plus S1-S5), rebuilt from scratch because
  the only earlier packaged copy predated this project's addition of
  Figures 7-9 and the Figure 2 promotion described above -- it only went
  up to Figure_6 and framed the event-validation content solely as
  "Fig. OR1.5". Includes a top-level README.txt and a
  MANIFEST_SHA256.txt checksum listing for every archived file.

## Note on ESM_1.tex's numeric tables

ESM_1.tex originally documented a 195-protocol x 30-independent-pool design
(master seed 20260804, 702,000 ABM trajectories at S0=8000) whose numbers
did not match what the supplementary-figure code in this project actually
ran (a smaller 30-cell, single-pool pilot). `supplementary_figures/
run_full_design.py` now actually runs the documented 195-protocol/30-pool
design end to end, and every table and figure in `ESM_1.tex` was
regenerated from that run. The new numbers are close to, but not
bit-identical to, the ones originally in this file -- reusing the same
seed value with a different (though statistically equivalent, and
substantially faster) simulation engine does not reproduce the same random
draw. See `../supplementary_figures/README.md` for the full production
pipeline.
